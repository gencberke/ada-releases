# Ada

Arkadaşlarla oynanan 3–8 kişilik çevrimiçi ada oyunu. Bu depo Windows indirmelerini ve otomatik güncellemeleri dağıtır.

**[Windows için Ada’yı indir](https://github.com/gencberke/ada-releases/releases/latest/download/Ada-win64.zip)**

1. ZIP dosyasını tamamen bir klasöre çıkar.
2. `Ada.bat` dosyasına çift tıkla. Yeni sürümler açılışta otomatik indirilir.
3. Adını yaz, oda kur veya arkadaşının oda koduyla katıl. Sunucu adresi hazırdır.

Ana menüdeki **Güncellemeleri denetle** düğmesiyle de yeni sürümleri kontrol edebilirsin. Güncelleme indirmesi kesilirse kurulu sürüm korunur.

Sunucuyu ev sahibi kendi bilgisayarında `Sunucu.bat` ile açar. Maç boyunca bu bilgisayar açık, uyanık ve internete bağlı kalmalıdır. Diğer oyuncuların Tailscale kurmasına veya GitHub hesabı açmasına gerek yoktur.

İlk kurulum için **Ada-win64.zip** kullan; **Ada-game-win64.zip** ve **version.json** otomatik güncelleyiciye aittir.
